# Вдвоём — приложение для пары (SwiftUI, iOS 17+)

## Как собрать на Mac
1. `brew install xcodegen`
2. В папке проекта: `xcodegen generate` → появится `Vdvoem.xcodeproj`
3. Откройте проект, в Signing выберите свою команду, поменяйте Bundle ID (`ru.vdvoem.app`)
4. Запуск на iPhone (⌘R)

Без XcodeGen: создайте проект iOS App (SwiftUI), удалите ContentView/App-файл, перетащите папку `Sources`
(кроме Info.plist), добавьте в Info ключ NSFaceIDUsageDescription.

## Что внутри
- **Синхронизация в реальном времени** через ваш сервер (PocketBase, маршруты `/api/vd/*`): код пары, живое соединение (SSE) с запасным опросом раз в 10 с, очередь отправки без потерь при плохом интернете, решение конфликтов «побеждает более новая правка».
- **Сегодня**: статус на 24 часа (20 видов), сон (оценка качества), трекер (вода, «я люблю тебя», объятия, кофе + свои счётчики), банка настроения, расстояние между вами.
- **Воспоминания**: общая фотолента с реакциями. **Карта**: общие метки с фото, точки партнёров (по желанию).
- **Игры по сети**: крестики-нолики, 4 в ряд, реверси; ходы видны у партнёра сразу; реванш; общий счёт побед.
- **Виджеты** (экран «Домой» и экран блокировки): статус, настроение, расстояние, общее фото, дни вместе.
- **Оформление**: 8 тем, 8 обоев чата, 16 значков приложения, стиль пузырей.
- Прежние разделы: чат, задачи, календарь, хотелки, списки, планы, файлы и карты (Face ID), вопрос дня, совместимость, капсула времени, голосование, радар подарков, заметки, даты.

## Сервер
Файлы лежат в `server/`. После любой правки в `server/pb_hooks` или `server/pb_migrations` выполните `python3 server/build-install.py` — он пересоберёт `server/install-vd.sh`.
Установка (безопасна, Кошелёк и HabitFlow не затрагиваются, перед этим делается копия базы, при сбое — откат):
1. Загрузите `install-vd.sh` в `/root` по SFTP.
2. `sudo bash /root/install-vd.sh`

## Ограничения
- Уведомления о ходах/статусах приходят только пока приложение открыто: настоящие push-уведомления невозможны при установке через ESign.
- Виджеты читают данные через App Group; если ESign не выдал группу, используется запасной канал через связку ключей (см. `Shared/WidgetShared.swift`).
- Проект собирается только в GitHub Actions; ошибки компиляции видны там.
