# Вдвоём — приложение для пары (SwiftUI, iOS 17+)

## Как собрать на Mac
1. `brew install xcodegen`
2. В папке проекта: `xcodegen generate` → появится `Vdvoem.xcodeproj`
3. Откройте проект, в Signing выберите свою команду, поменяйте Bundle ID (`ru.vdvoem.app`)
4. Запуск на iPhone (⌘R)

Без XcodeGen: создайте проект iOS App (SwiftUI), удалите ContentView/App-файл, перетащите папку `Sources`
(кроме Info.plist), добавьте в Info ключ NSFaceIDUsageDescription.

## Что внутри
- Онбординг (8 шагов): имена, дата начала, цвета пары, тема/шрифт/скругление, выбор функций, коды пары, Face ID и уведомления
- Вкладки: Задачи, Календарь, Хотелки, Списки, Ещё
- Ещё: Чат, Планы, Файлы и Карты (под Face ID), Вопрос дня, Тест на совместимость, Игры (крестики-нолики, 4 в ряд, реверси),
  Капсула времени, Голосование, Подарочный радар, Заметки, Наши даты, Настроение, Идеи свиданий, Настройки
- Кастомизация: пары цветов + свой цвет каждому, тема, 4 стиля шрифта, скругление, вибро, включение/выключение функций,
  порядок и состав нижней панели (первые 4 включённые функции)

## Важно
Данные хранятся локально в JSON (Documents/vdvoem.json). Синхронизации между двумя телефонами пока нет:
чат, общие задачи и ответы работают в рамках одного устройства. Следующий шаг — слой синхронизации
(CloudKit Sharing или свой сервер), `Store.data` уже единая точка записи.
Проект не компилировался в этой среде (нет Swift), возможны мелкие правки при первой сборке.
