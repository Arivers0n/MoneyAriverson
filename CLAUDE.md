# Копилка (Koshelek) — памятка для Claude Code

Личное приложение для денег: iOS (SwiftUI) + Android (Compose) + сервер синхронизации (PocketBase на VPS). Владелец: Arivers0n. **Отвечать всегда по-русски.**

## Среда
- У владельца нет Mac. iOS собирается GitHub Actions (`.github/workflows/build.yml`, XcodeGen по `project.yml`), релиз `latest` содержит неподписанный `Koshelek.ipa`; подписывается в ESign, **bundle ID менять нельзя** (данные не перенесутся). Android — `android.yml`, автообновление через сервер.
- Локально SwiftUI не собрать, проверка — через CI.

## Структура
- `Koshelek/` — приложение: Core, Models, Logic, Brain, Savings, Advisor (ИИ-советник), Sync, Services, Customization (темы, иконки, фоны), Feel, Intents (Siri), TestData, Views/.
- `KoshelekWidget/` — виджет.
- `android/` — нативный Android на Compose.
- `server/` — установка одной командой на VPS: `install.sh`, `pb_hooks/`, `pb_migrations/`, `README.md`. Маршруты `/api/kp/*` (ИИ, OAuth-callback, ping и др.). Рядом живёт модуль HabitFlow (`/api/hf/*`) — **общий аккаунт (коллекция users)**, данные раздельные.
- Сервер по умолчанию: `https://2-27-25-140.sslip.io:8443`.

## Возможности (из истории)
Бюджет и счета, копилки с автоправилами, кредиты/долги/микрозаймы с графиком платежей, подписки и календарь, голосовой ввод своими словами и скан чеков (Claude API), ИИ-советник, семейный бюджет, вход и синхронизация iPhone/iPad, Siri, виджет, кастомизация (готовые темы, фоны, 16 значков, вкладки Тема/Иконки/Экран), iPad в две колонки + клавиатурные сочетания.

## Пожелания владельца
- Минималистичный, незагруженный дизайн в духе Qalta, очень удобный голосовой ввод.
- Синхронизация с Obsidian: отчёты и перенос данных из приложения в Obsidian (не сделано).
- Приложение только про деньги, не «приложение для жизни».

## Связь с HabitFlow
HabitFlow (репо Arivers0n/HabitFlow) взял отсюда вход, синхронизацию, ИИ-слой и кастомизацию. Любые изменения общего API (`/api/kp/ai`, `/api/kp/oauth-callback`, users) могут сломать оба приложения — проверять оба.
