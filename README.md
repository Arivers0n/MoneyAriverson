# Лад — приложение для жизни

Деньги, дела, привычки и бонусные карты в одном месте. Голосом можно сказать что угодно: трату, задачу, покупку, привычку. ИИ-советник подсказывает, где вы теряете деньги и как быстрее закрыть долги.

## Как установить

1. Откройте вкладку **Releases** этого репозитория, релиз **latest**, и скачайте `Koshelek.ipa`.
   Другой путь: **Actions** → последний зелёный запуск → артефакт `Koshelek-ipa`.
2. Подпишите `.ipa` своим сертификатом (ESign, Sideloadly, AltStore) и установите.
3. Откройте приложение: **Настройки** (шестерёнка) → вставьте ключ Claude API → «Сохранить и проверить».

Каждый пуш в `main` автоматически собирает новую версию.

## Голос без клавиатуры

- **В приложении:** кнопка «Голосом». Микрофон включается сразу, говорите как обычно.
- **Siri:** «Привет, Siri, запиши в Лад». Siri спросит «Что записать?», дальше говорите своими словами.
- **Виджет:** на экране «Домой» есть кнопки «Голосом», «Скан» и «Вручную», на экране блокировки — кнопка микрофона.
- **Кнопка «Действие»:** Настройки → Кнопка «Действие» → Быстрая команда → «Записать в Лад».

## Ключ Claude API

Ключ нужен, чтобы понимать разговорную речь, сканировать чеки и графики платежей и делать разбор месяца. Создаётся на console.anthropic.com → API Keys. Для разбора используется Claude Haiku 5.5, одна запись стоит доли копейки. Без ключа работает простой разбор фраз вроде «кофе 250, такси 400».

## Перенос из веб-версии

В веб-версии: «Анализ» → «Скачать CSV». В приложении: «Настройки» → «Импортировать CSV из веб-версии».

## Сборка

Проект описан в `project.yml` (XcodeGen). На Mac:

```
brew install xcodegen && xcodegen && open Koshelek.xcodeproj
```
