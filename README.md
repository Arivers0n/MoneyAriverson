# Копилка

Личные финансы для iPhone и iPad:
- бюджет и счета;
- копилки с автоправилами;
- кредиты и подписки с календарём;
- анализ и ИИ-советник.

Записывать можно голосом своими словами или сканом чека. Синхронизация идёт через ваш сервер, есть семейный бюджет.

## Установка приложения

1. **Releases** → **latest** → скачать `Koshelek.ipa`.
2. Подписать в ESign своим сертификатом. **Bundle ID не менять**, иначе данные не перенесутся.
3. Настройки (шестерёнка):
   - ключ Claude API — для голоса, скана и советника;
   - «Войти и синхронизировать» — адрес вашего сервера и аккаунт.

## Сервер синхронизации

См. [server/README.md](server/README.md). Ставится одной командой на VPS.

## Сборка

Каждый пуш в `main` собирает новый `.ipa` (GitHub Actions, XcodeGen).
